LIBFT is the very first project in the 1337 curriculum,The main reason to why libft is the very first project to your journey in 1337. Its biggest reason is the fact that behind these small functions are alot of interesting edge cases for example the concept of memory overlapping in memmove, or the fact that you would need to handle all possible cases where a memory leak could happen, not to also mention how data can be chained together dynamically in RAM and how to move and modify that structure. and also to just understand how memory and Error Handling works in C. which is a very good quality in now-a-days ai infested job markets.

## LIBFT

LIBFT is a personal C library made by students as part of the 1337 curriculum, its purpose is to recreate several functions from the standard C library, concentrating around string manipulation, character checking, memory behavior and a new data storing system (LINKED LISTS).
